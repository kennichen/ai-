## 一、收购逻辑

### 1.1 为什么收店比开���更好？

| 对比项 | 开新店 | **收旧店** |
|:------|:-----:|:----------:|
| 启动资金 | **60-100万** | **10-30万** |
| 回本周期 | **12-18个月** | **2-3个月** |
| 装修投入 | 15-30万 | 几乎为零 |
| 设备成本 | 20-40万 | 2-5万（二手） |
| 租金占比 | 25-35% | **<10%**（重新谈判） |
| 会员基础 | 0 | 已有存量会员 |
| 品牌认知 | 0 | 周边已有人知道 |

### 1.2 核心公式

> **利润 = （低成本收购 + 低租金运营）—（课时负债消化 + 人员成本）**

收店能赚钱的本质是：**收购价比新开店低很多，但通过租金谈判和成本控制，让运营成本也远低于同行。**

| 渠道 | 效率 | 说明 |
|:----|:---:|:-----|
| 个人IP引流 | ⭐⭐⭐⭐⭐ | "收店"人设→濒死老板主动找上门（0成本） |

#### 1.2 快速筛选（5分钟判断）

**打电话问老板这5个问题，快速判断值不值得跑一趟：**

| # | 问题 | 值 得 看 的 答 案 | 不 用 看 的 答 案 |
|:-:|:-----|:----------------|:----------------|
| 1 | 开了多久？ | 1-3年（有会员基础） | <6个月（还没做起来） |
| 2 | 面积多大？ | 300-800㎡ | <200㎡（太小）或 >1000㎡（太大） |
| 3 | 月租金多少？ | 2-5万（可谈） | >10万（租金压死人） |
| 4 | 为什么转让？ | "合伙人不干了""家里有事" | "赚不到钱"（说明救不了） |
| 5 | 剩余课时负债？ | <50万 | >100万（要消化很久） |

### Phase 2：尽调评估（D8-D21）

#### 2.1 现地考察清单

**去现场必须看什么：**

| 维度 | 检查项 | 好信号 | 坏信号 |
|:----|:------|:-------|:-------|
| 位置 | 周边小区入住率 | 晚上亮灯率>70% | 亮灯率<40% |
| 位置 | 门口人流量 | 下班时间有人经过 | 一整条街没人 |
| 设备 | 设备新旧 | 还有3-5年寿命 | 锈迹斑斑 |
| 设备 | 品牌 | 进口/国产主流 | 杂牌 |
| 环境 | 整洁度 | 干净整洁 | 脏乱差 |
| 环境 | 气味 | 通风良好 | 霉味/汗臭味重 |
| 人气 | 到店会员数 | 高峰时段有人 | 空无一人 |
| 人气 | 教练状态 | 有教练在带课 | 教练都在玩手机 |
| 周边 | 竞品 | 距离>1公里 | 门口就有一家 |
| 周边 | 社区配套 | 有学校、超市 | 什么都没有 |

#### 2.2 财务核查清单

**问老板要这3样东西：**

| 资料 | 为什么要看 | 重点看什么 |
|:----|:---------|:----------|
| **银行流水** | 看真实营收 | 月均入账多少、是否有大额异常进出 |
| **课时负债表** | 看真实负债 | 总节数、总金额、单价、到期时间 |
| **固定成本清单** | 看运营效率 | 租金占比、人力占比、与营收的比例 |

#### 2.3 房东谈判

**这是整个收购最关键的一步！**

**谈判目标**：把租金降到**营收的10%以下**

**话术参考**：
> "老板，我接手的是个烂摊子，不是为了赚钱，是为了不让他关店影响你这栋楼的人气。
> 如果我接手，我能保证这里3年不关门，但前提是租金要降。
> 你现在空着也是空着，降了租还有稳定收入。"

**谈判底线**：

| 租金现价 | 谈判目标 | 底线 |
|:--------:|:-------:|:----:|
| 50元/㎡/月 | 35元/㎡/月 | 40元/㎡/月 |
| 80元/㎡/月 | 50元/㎡/月 | 60元/㎡/月 |
| 100元/㎡/月 | 60元/㎡/月 | 75元/㎡/月 |
| 150元/㎡/月 | 80元/㎡/月 | 100元/㎡/月 |

#### 2.4 出价模型

**收购价不是"老板要多少"，是"算出来值多少"：**

```
收购价上限 = （月净现金流预估 × 6个月）— 接手课时负债
```

**举例**：
- 预估月净现金流 = 3万
- 接手课时负债 = 72万
- 收购价上限 = 3×6 - 72 = **负数**
- 结论：这家店除非0元接手，否则不划算

**另一组数据**：
- 预估月净现金流 = 8万
- 接手课时负债 = 30万
- 收购价上限 = 8×6 - 30 = **18万**
- 结论：18万以内可以考虑

### Phase 3：交割与整改（D22-D45）

#### 3.1 交割清单

| 事项 | 说明 |
|:----|:-----|
| 签转让协议 | 必含：债权债务清晰界定、员工交接、会员服务承诺 |
| 重签租赁合同 | 与房东直接签，不通过原老板转租 |
| 变更营业执照 | 法人变更或新注册 |
| 变更美团/点评账号 | 绑定新的联系方式 |
| 变更银行账户 | 与原老板账户彻底切割 |
| 会员告知 | 正式通知会员：店已换老板，服务不受影响 |

#### 3.2 整改三板斧

| # | 动作 | 预期效果 | 投入 |
|:-:|:-----|:--------|:---:|
| 1 | **降租金** | 现金流质的飞跃 | 0元 |
| 2 | **裁冗余人员** | 月省2-5万 | 0元 |
| 3 | **美团/点评运营启动** | 3个月评分从3.9到4.3+ | 5,000元/月 |

#### 3.3 消课方案

**课时负债不是负担，是拉新的武器：**

| 策略 | 具体做法 | 效果 |
|:----|:--------|:----|
| 消课捆绑续费 | "剩余20节，现在续30节送10节" | 把老会员变成新会员 |
| 消课转介绍 | "带朋友来体验，免费送2节消课" | 老会员是最好的销售 |
| 消课升级 | "剩余次卡补差价升级私教" | 提升客单价 |

### Phase 4：稳定运营（D46-D90）

#### 4.1 月度关键指标

| 指标 | 健康值 | 预警值 |
|:----|:-----:|:-----:|
| 月新增会员 | >30人 | <10人 |
| 月续费率 | >57% | <40% |
| 月消课量 | >300节 | <150节 |
| 月新客营收 | >8万 | <3万 |
| 美团评分 | >4.3 | <4.0 |

#### 4.2 合伙人运营的交接

- 第1个月：你亲自盯
- 第2个月：你带合伙人盯
- 第3个月：合伙人独立运营，你每周复盘一次
- 第4个月起：每月看一次财报拿分润

## 三、风险控制

### 3.1 收店的"三不接"原则

| # | 不要接 | 原因 |
|:-:|:-------|:-----|
| 1 | **房租占比>30%的** | 除非能降到位，否则根本救不活 |
| 2 | **课时负债>100万的** | 消化周期超过2年，现金流撑不住 |
| 3 | **位置明显有硬伤的** | 不是在巷子里，就是周边没小区 |

### 3.2 止损线

| 时间点 | 应达到的状态 | 达不到怎么办 |
|:------:|:-----------|:------------|
| 接手第1个月 | 完成整改，团队到位 | 加派人手，不要拖 |
| 接手第3个月 | 月营收>月成本 | 启动紧急措施（降价促销） |
| 接手第6个月 | 累计现金流回正 | 如果还是负数→准备转让 |
| 接手第12个月 | 课时负债消化50%+ | 检查消课策略 |

```
输入参数：
  月预估营收：_______万元
  月固定成本：_______万元
```

## 六、最后的忠告

1. **没有调查就没有发言权**——看10家店再决定收不收第1家
2. **不要被"低价"冲昏头**——0元收店不代表0元风险
3. **最难的不是收，是管**——没有好的运营合伙人，再便宜的店也是坑
4. **不要在晚上做决定**——尽调完睡一觉，第二天再决策
5. **第一条止损线比第一条利润重要**——收之前就想好什么时候撤
