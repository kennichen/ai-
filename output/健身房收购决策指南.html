一、收购逻辑

1.1 为什么收店比开���更好？

1.2 核心公式

利润 = （低成本收购 + 低租金运营）—（课时负债消化 + 人员成本）

收店能赚钱的本质是：收购价比新开店低很多，但通过租金谈判和成本控制，让运营成本也远低于同行。

2.3 房东谈判

这是整个收购最关键的一步！

谈判目标：把租金降到营收的10%以下

话术参考：

"老板，我接手的是个烂摊子，不是为了赚钱，是为了不让他关店影响你这栋楼的人气。 如果我接手，我能保证这里3年不关门，但前提是租金要降。 你现在空着也是空着，降了租还有稳定收入。"

谈判底线：

租金现价 谈判目标 底线
50元/㎡/月 35元/㎡/月 40元/㎡/月
80元/㎡/月 50元/㎡/月 60元/㎡/月
100元/㎡/月 60元/㎡/月 75元/㎡/月
150元/㎡/月 80元/㎡/月 100元/㎡/月

2.4 出价模型

收购价不是"老板要多少"，是"算出来值多少"：

收购价上限 = （月净现金流预估 × 6个月）— 接手课时负债

举例： - 预估月净现金流 = 3万 - 接手课时负债 = 72万 - 收购价上限 = 3×6 - 72 = 负数 - 结论：这家店除非0元接手，否则不划算

另一组数据： - 预估月净现金流 = 8万 - 接手课时负债 = 30万 - 收购价上限 = 8×6 - 30 = 18万 - 结论：18万以内可以考虑

事项 说明

3.2 整改三板斧

# 动作 预期效果 投入
1 降租金 现金流质的飞跃 0元
2 裁冗余人员 月省2-5万 0元

3.3 消课方案

课时负债不是负担，是拉新的武器：

策略 具体做法 效果
消课捆绑续费 "剩余20节，现在续30节送10节" 把老会员变成新会员
消课转介绍 "带朋友来体验，免费送2节消课" 老会员是最好的销售
消课升级 "剩余次卡补差价升级私教" 提升客单价

4.1 月度关键指标

指标 健康值 预警值
月新增会员 >30人 <10人
月续费率 >57% <40%
月消课量 >300节 <150节

4.2 合伙人运营的交接

  • 第1个月：你亲自盯
  • 第2个月：你带合伙人盯
  • 第3个月：合伙人独立运营，你每周复盘一次
  • 第4个月起：每月看一次财报拿分润

三、风险控制

3.1 收店的"三不接"原则

# 不要接 原因
1 房租占比>30%的 除非能降到位，否则根本救不活
2 课时负债>100万的 消化周期超过2年，现金流撑不住
3 位置明显有硬伤的 不是在巷子里，就是周边没小区

3.2 止损线

时间点 应达到的状态 达不到怎么办
接手第1个月 完成整改，团队到位 加派人手，不要拖
接手第3个月 月营收>月成本 启动紧急措施（降价促销）
接手第6个月 累计现金流回正 如果还是负数→准备转让
接手第12个月 课时负债消化50%+ 检查消课策略

六、最后的忠告

  1. 没有调查就没有发言权——看10家店再决定收不收第1家
  2. 不要被"低价"冲昏头——0元收店不代表0元风险
  3. 最难的不是收，是管——没有好的运营合伙人，再便宜的店也是坑
  4. 不要在晚上做决定——尽调完睡一觉，第二天再决策
  5. 第一条止损线比第一条利润重要——收之前就想好什么时候撤
